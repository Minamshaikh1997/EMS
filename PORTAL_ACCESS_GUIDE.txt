========================================
EMS Portal Open Nahi Ho Raha Hai - Solutions
========================================

Aapke paas 2 tarike hain portal access fix karne ke:

========================================
METHOD 1: Automated Fix Script (Recommended)
========================================

1. fix_portal.bat file par RIGHT CLICK karein
2. "Run as administrator" par click karein
3. Script automatically:
   - Apache status check karega
   - Port 80/443 check karega
   - Portal URLs open karega
4. Browser mein portal khul jana chahiye

========================================
METHOD 2: Manual Steps
========================================

STEP 1: XAMPP Control Panel Check karein
------------------------------------------
1. XAMPP Control Panel kholin
2. Apache ke paas "Running" status hona chahiye (GREEN color)
3. MySQL ke paas bhi "Running" status hona chahiye

Agar Apache start nahi ho raha:
- Apache par "Start" button click karein
- Agar error aaye to error message note karein
- Apache error log check karein: C:\xampp\apache\logs\error.log

STEP 2: Direct URLs Try karein
-------------------------------
Inme se koi ek URL browser mein try karein:

1. http://localhost/EMS/
2. http://localhost/EMS/login.php
3. http://127.0.0.1/EMS/
4. http://127.0.0.1/EMS/login.php

STEP 3: Port 80 Check karein
----------------------------
Agar Apache start nahi ho raha, to port 80 busy ho sakta hai:

1. Command Prompt (CMD) ko Administrator ke taur par open karein
2. Ye command run karein:
   netstat -ano | findstr :80
3. Agar koi output aaye:
   - Task Manager (Ctrl+Shift+Esc) kholin
   - Us PID ko find karein
   - Process end karein
   Ya phir CMD mein:
   taskkill /F /PID [PID_NUMBER]

Common programs jo port 80 use karte hain:
- Skype
- IIS (Internet Information Services)
- World Wide Web Publishing Service
- VMware
- TeamViewer

STEP 4: Firewall/Antivirus Check karein
---------------------------------------
1. Windows Firewall check karein:
   - Windows + R press karein
   - firewall.cpl type karein
   - "Allow an app through firewall" par click karein
   - Apache HTTP Server ko ALLOW karein

2. Antivirus temporarily disable karein:
   - Antivirus Apache ko block kar sakta hai
   - Temporary disable karke try karein

STEP 5: Apache Service Restart karein
-------------------------------------
1. XAMPP Control Panel mein Apache stop karein
2. 2 seconds wait karein
3. Apache start karein
4. Agar still nahi ho to XAMPP completely close karein
5. Phir se XAMPP Administrator ke taur par open karein
6. Apache start karein

STEP 6: Apache Config Check karein
-----------------------------------
1. Ye file open karein: C:\xampp\apache\conf\httpd.conf
2. Ye lines check karein:
   
   Listen 80
   ServerName localhost:80
   DocumentRoot "C:/xampp/htdocs"
   
3. Sab sahi hona chahiye
4. Apache restart karein

========================================
COMMON ISSUES AND SOLUTIONS
========================================

ISSUE 1: "Apache shutdown unexpectedly"
SOLUTION:
1. C:\xampp\apache\logs\error.log check karein
2. Port 80 already in use ho sakta hai
3. Skype/IIS close karein
4. Apache restart karein

ISSUE 2: "Port 80 in use"
SOLUTION:
1. Task Manager se conflicting processes end karein
2. Ya phir Apache port change karein:
   - C:\xampp\apache\conf\httpd.conf open karein
   - Listen 80 ko Listen 8080 mein change karein
   - ServerName localhost:80 ko ServerName localhost:8080 mein change karein
   - Save karein aur restart karein
   - Phir browser mein http://localhost:8080/EMS/ try karein

ISSUE 3: "Forbidden" error
SOLUTION:
1. C:\xampp\apache\conf\extra\httpd-xampp.conf check karein
2. Directory permissions check karein
3. C:\xampp\htdocs folder ke permissions check karein

ISSUE 4: "404 Not Found" error
SOLUTION:
1. URL sahi hai ya nahi check karein
2. EMS folder C:\xampp\htdocs\EMS\ mein hai ya nahi check karein
3. .htaccess file check karein agar hai

ISSUE 5: "Database Connection Failed"
SOLUTION:
1. MySQL running hai ya nahi check karein
2. config/db.php file check karein
3. Database name, username, password sahi hon
4. MySQL start karein aur try karein

ISSUE 6: Blank page / White screen
SOLUTION:
1. PHP errors ho sakte hain
2. Browser console check karein (F12)
3. Apache error log check karein
4. PHP display_errors enable karein:
   - C:\xampp\php\php.ini open karein
   - display_errors = On karein
   - Save karein aur Apache restart karein

========================================
XAMPP KO ADMINISTRATOR KE TAUR PAR RUN KAREIN
========================================

Bahut baar XAMPP ko Administrator permissions ke bagair run karne se issues hoti hain:

1. XAMPP Control Panel close karein
2. Desktop ya Start Menu se XAMPP par RIGHT CLICK karein
3. "Run as administrator" par click karein
4. Apache aur MySQL start karein

========================================
WINDOWS SERVICES CHECK
========================================

Agar XAMPP kaam nahi kar raha:

1. Windows + R press karein
2. services.msc type karein aur Enter
3. Ye services check karein:
   - Apache2.4 (agar installed hai)
   - MySQL
4. Right click karke Start karein

========================================
ALTERNATIVE: USE DIFFERENT LOCAL SERVER
========================================

Agar XAMPP hi kaam nahi kar raha:

Option 1: WampServer use karein
- Download: https://www.wampserver.com/
- Install karein aur use karein

Option 2: Laragon use karein
- Download: https://laragon.org/
- Bahut fast aur easy hai

Option 3: PHP Built-in Server use karein
1. CMD mein C:\xampp\htdocs\EMS folder par jayein
2. Ye command run karein:
   C:\xampp\php\php.exe -S localhost:8000
3. Browser mein http://localhost:8000/ try karein

========================================
AFTER PORTAL OPENS
========================================

Portal open ho jane ke baad:

1. Login page dikhega: http://localhost/EMS/
2. Default credentials:
   - Admin: Check database ya config files
   - Employee: Check database
3. Database create karein agar nahi hai:
   - Database name: employee_leave_system
   - Import karein SQL file

========================================
QUICK FIX COMMANDS (Run CMD as Administrator)
========================================

Ye commands ek saath run karein:

taskkill /F /IM httpd.exe
taskkill /F /IM mysqld.exe
net stop apache2.4
net stop mysql
net start apache2.4
net start mysql
echo.
echo Now try: http://localhost/EMS/

========================================
STILL NOT WORKING?
========================================

Agar abhi bhi portal nahi khul raha:

1. Error logs check karein:
   - C:\xampp\apache\logs\error.log
   - C:\xampp\mysql\data\mysql_error.log
   - Browser console (F12)

2. XAMPP reinstall karein:
   - Pehle backup lein (htdocs\EMS folder)
   - XAMPP uninstall karein
   - Phir se install karein
   - EMS folder restore karein

3. Error message screenshot le kar support se madad lein
