================================================================================
                    MYSQL NOT WORKING - TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: MySQL is not starting or not working in XAMPP
SOLUTION: Follow these steps in order

================================================================================
STEP 1: CHECK XAMPP CONTROL PANEL
================================================================================

1. Open XAMPP Control Panel (Search in Windows Start Menu)
2. Look at the MySQL row:
   
   IF YOU SEE: Red "Start" button
   → MySQL is stopped, click Start
   
   IF YOU SEE: Green "Stop" button  
   → MySQL is running (but maybe on different port)
   
   IF YOU SEE: Yellow/Orange with "Starting..."
   → MySQL is trying to start but stuck
   
   IF YOU SEE: Error message in the log
   → Read the error message carefully (see Step 3)

================================================================================
STEP 2: CHECK FOR PORT CONFLICTS
================================================================================

MySQL uses port 3306 by default. If another program is using it, MySQL won't start.

TO CHECK:
1. Open Command Prompt as Administrator
2. Type: netstat -ano | findstr :3306
3. If you see output, another program is using port 3306

TO FIX:
Option A: Stop the other program using port 3306
Option B: Change MySQL port:
  1. In XAMPP, click "Config" next to MySQL
  2. Open "my.ini"
  3. Find: port=3306
  4. Change to: port=3307
  5. Save file
  6. Restart MySQL

================================================================================
STEP 3: CHECK MYSQL ERROR LOG
================================================================================

1. In XAMPP Control Panel, look at the MySQL log (bottom section)
2. Common errors and solutions:

ERROR: "Can't create/write to file 'C:\xampp\mysql\data\ibdata1'"
SOLUTION: 
  - Run XAMPP as Administrator
  - Check folder permissions: C:\xampp\mysql\data
  - Right-click folder → Properties → Security → Give Full Control

ERROR: "InnoDB: Unable to lock ./ibdata1, error: 11"
SOLUTION:
  - Another MySQL instance is running
  - Open Task Manager (Ctrl+Shift+Esc)
  - Find "mysqld.exe" in Processes
  - End task
  - Try starting MySQL again

ERROR: "MySQL shutdown unexpectedly"
SOLUTION:
  - Go to C:\xampp\mysql\data\
  - Rename "data" folder to "data_old"
  - Copy "backup" folder and rename to "data"
  - Copy ibdata1 from data_old to new data folder
  - Start MySQL

ERROR: "Port 3306 in use"
SOLUTION:
  - See Step 2 above
  - Or disable Skype/Teams/Slack (they use port 3306 sometimes)

================================================================================
STEP 4: ALTERNATIVE START METHOD
================================================================================

If XAMPP Control Panel doesn't work, try starting MySQL manually:

1. Open Command Prompt as Administrator
2. Type: cd C:\xampp\mysql\bin
3. Type: mysqld.exe --console
4. Watch for errors
5. If it starts, open another command prompt and test:
   Type: mysql -u root

================================================================================
STEP 5: CHECK WINDOWS SERVICES
================================================================================

1. Press Windows Key + R
2. Type: services.msc
3. Press Enter
4. Look for "MySQL" or "MySQL80" in the list
5. Check its status:
   - If "Running" → MySQL is running
   - If "Stopped" → Right-click → Start
   - If "Disabled" → Right-click → Properties → Startup type → Automatic

================================================================================
STEP 6: DISABLE ANTIVIRUS/FIREWALL TEMPORARILY
================================================================================

Sometimes antivirus blocks MySQL:

1. Temporarily disable Windows Defender Firewall:
   - Windows Security → Firewall → Turn off (temporarily)
   
2. Temporarily disable antivirus (if installed)

3. Try starting MySQL again

4. Re-enable firewall after MySQL starts

================================================================================
STEP 7: REINSTALL XAMPP (LAST RESORT)
================================================================================

If nothing works:

1. Backup your database:
   - Copy C:\xampp\mysql\data\ (especially your database folders)
   
2. Uninstall XAMPP

3. Download fresh XAMPP from: https://www.apachefriends.org/

4. Install XAMPP (same version or newer)

5. Restore your database folder

6. Start MySQL

================================================================================

- Works out of the box with PHP

   tasklist | findstr mysql

   netstat -ano | findstr :3306
   
4. Try connecting:
